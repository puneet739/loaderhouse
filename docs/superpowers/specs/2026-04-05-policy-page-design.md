# Policy Page Design

## Summary

Create a static privacy policy page for the Loaderhouse website that is published at `/policy` on GitHub Pages. The page will describe privacy practices for the `Loaderhouse` brand operated by `N & M KANYSHA LOGISTICS LLP`.

## Goals

- Make a privacy policy available at `https://www.loaderhouse.com/policy`.
- Cover the current website and planned logistics platform at a launch-stage level.
- Use conservative language that avoids overpromising on security, data sharing, or legal guarantees.
- Reuse the current site styling so the page feels native to the existing marketing site.

## Scope

- Add `policy/index.html`.
- Update the homepage footer privacy link to point to `/policy`.
- Include sections for data collected, purposes, disclosures, cookies, retention, security, rights, children, cross-border processing, policy updates, and contact details.

## Constraints

- The repo is a plain static site served by GitHub Pages.
- The policy must use the provided entity details:
  - Operator: `N & M KANYSHA LOGISTICS LLP`
  - Brand/App: `Loaderhouse`
  - Contact: `info@loaderhouse.com`
- No unsupported legal promises should be introduced.

## Notes

- This is a privacy policy, not a substitute for terms of service, shipment rules, or a lawyer-reviewed compliance pack.
- The registered postal address and designated grievance officer details are not yet available, so the page should avoid fabricating them.
